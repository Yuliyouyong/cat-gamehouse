## 🎨 视觉风格与设计特色

- **莫兰迪粉绿手账美学**：莫兰迪草木绿（#708A66 / #A3B899）与温柔复古粉（#D4A5A5 / #B57E7E），搭配温润天然和纸底色；
- **纯正手绘原版白猫**：紫色大蝴蝶结 + 珍珠中心 + 夸张长假睫毛 + 闪烁八角星眼 + 甜美腮红，100% 贯穿所有小游戏；
- **沉浸式翻开大书形态**：中央清晰书脊、多层书页堆叠厚度感、手绘纸张微孔与呼吸光斑；
- **双端量身定制交互**：
  - **电脑端（PC）**：鼠标悬停微动、第一次点击翻开手账简介、第二次点击直达游戏；
  - **手机端（Mobile）**：左右滑动手势（Touch Swipe）翻页、底部 7 房间触控横滑底栏、内置手账九宫格软键盘。
